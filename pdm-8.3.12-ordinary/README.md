# Консоль кода для PDM — 1С 8.3.12.1529 (обычное приложение)

Отдельная упрощённая ветка исходников. Исходный `console.epf` и ветка `main` не изменяются.

## Назначение

Минимальная консоль для запуска фрагментов встроенного языка в клиентском контексте обычного приложения. HTML/JavaScript-редактор исходной управляемой формы сюда не переносится.

## Состав

- `OrdinaryFormModule.bsl` — модуль обычной формы.
- `FormLayout.md` — требования к элементам формы и обработчикам.

## Совместимость и ограничения

- Целевая платформа: 1С:Предприятие 8.3.12.1529.
- Режим: обычное приложение.
- Не используются управляемые формы, асинхронные методы, HTML-поле и JavaScript.
- Код выполняется на клиенте через `Выполнить()`. Вывод `Сообщить()` идёт в штатное окно сообщений 1С.
- Ветка содержит исходный модуль и описание формы, но не скомпилированный бинарный `.epf`. Для получения `.epf` нужно собрать и проверить обработку в Designer 8.3.12.1529.

## Сборка

Создать отдельную внешнюю обработку в Designer 8.3.12.1529, добавить обычную форму по `FormLayout.md`, перенести модуль из `OrdinaryFormModule.bsl` и сохранить как `.epf`. Основную конфигурацию PDM не изменять.
