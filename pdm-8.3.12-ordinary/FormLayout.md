# Обычная форма

Создать форму внешней обработки с типом **Обычная**.

| Имя элемента | Тип элемента | Свойства |
|---|---|---|
| `Код` | ПолеТекстовогоДокумента | Многострочное, растягивается по ширине и высоте |
| `Результат` | ПолеТекстовогоДокумента | Многострочное, только просмотр |
| `Выполнить` | Кнопка | Нажатие → `ВыполнитьНажатие` |
| `Очистить` | Кнопка | Нажатие → `ОчиститьНажатие` |

Назначить форме обработчик **ПриОткрытии** из модуля формы.

Рекомендуемое расположение: `Код` сверху, кнопки под ним, `Результат` снизу. У `Результат` установить режим только просмотра.
